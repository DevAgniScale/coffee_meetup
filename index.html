07 · How Our Agent Works
💬 Built for Discord

From question to answer, step by step

In simple terms: it's a bot that sits inside our Discord server, reads what a student asks, checks our own course file for the real answer first, and only falls back to general knowledge if the answer isn't there. It never shares secrets, and it always replies right there in the chat.

STEP 1

Student asks a question on Discord.

STEP 2

Discord Bot receives the message.

STEP 3

AI reads course_info.txt for real course data.

STEP 4

Question + info are sent to Gemini.

STEP 5

If found, Gemini answers from the course file.

STEP 6

If not found, it uses general knowledge instead.

STEP 7

Asked for API keys or secrets? AI politely refuses.

STEP 8

Answer is sent back to the student on Discord.

11 · Why This Actually Worked

Plan first, prompt second, every time

  • Define the problem before opening a code editor.
  • Design the workflow: what happens, step by step.
  • Pick the components: which tools, which model, which files.
  • Write the security rules: what the agent must never do.
  • Define expected behavior: what a good answer looks like.
  • Only then, write the detailed prompt.

When planning is clear, AI doesn't guess, it executes. That's why engineering always puts planning before coding. Real enterprise projects take this further: multiple files, multiple workflows, several LLMs each doing one job (one plans, one retrieves, one validates, one reports), human-in-the-loop approvals, memory, RAG, and MCP connecting external tools. Building systems like that takes deep planning and AI-first thinking, not just a good prompt.

13 · A Real One: Salesforce Agentforce

This pattern is already running in production

Salesforce's own multi-agent platform, Agentforce, is built on something called the Atlas Reasoning Engine, an orchestration layer that runs retrieval, planning, and action-taking as parallel nodes instead of one long chain. This is a simplified version of that pattern.

How it actually gets handled: a large retailer (10,000+ staff, roughly $2B in revenue) used this exact pattern for financial reporting. An AnalyzerAgent pulled KPIs and flagged anomalies, a NarratorAgent turned that into an executive summary, and a RiskCriticAgent checked it against compliance rules, all before a human signed off. Report time dropped from 15 days to about 35 minutes, cost per report fell from around $2,200 to about $9, and the error rate dropped from roughly 3 per report to 0.3.
